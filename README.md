# UNIVERSE X

An immersive, mobile-first space exploration experience by Arpan Goswami.

## Phase 1 starter

This release includes:
- Responsive dark cosmic homepage
- Animated starfield and cinematic hero
- Interactive eight-planet profile selector
- Mobile navigation
- Accessible reduced-motion support
- React + TypeScript + Vite foundation

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

The production output is written to `dist/`.

## Cloudflare Pages

Connect the GitHub repository to Cloudflare Pages with:
- Framework preset: Vite
- Build command: `npm run build`
- Build output directory: `dist`

No paid APIs or backend services are required for this starter.
