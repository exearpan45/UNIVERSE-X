# UNIVERSE X

An immersive, responsive space-exploration website.

## Features
- Responsive cosmic landing page
- Interactive profiles for all eight planets
- Deep-space learning cards
- Low-power mode for modest devices
- Mobile navigation and reduced-motion support
- No API keys or paid services required

## Deployment
GitHub Actions automatically publishes this static website to GitHub Pages whenever changes are pushed to `main`.

After the first workflow run, open **Settings → Pages** and ensure the source is **GitHub Actions**.

Expected URL: https://exearpan45.github.io/UNIVERSE-X/
